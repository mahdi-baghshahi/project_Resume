# رزومه شخصی - React + Tailwind CSS

این پروژه یک وب‌سایت رزومه شخصی است که با React، Tailwind CSS، و React Router ساخته شده است. این پروژه از یک پروژه HTML/CSS/JS اصلی تبدیل شده و طراحی و عملکرد آن کاملاً حفظ شده است.

## ویژگی‌ها

- ✨ طراحی مدرن و واکنش‌گرا
- 🎨 استفاده از Tailwind CSS برای استایل‌دهی
- ⚛️ ساخته شده با React
- 🧭 استفاده از React Router برای ناوبری
- 📱 کاملاً واکنش‌گرا برای تمام دستگاه‌ها
- 🇮🇷 پشتیبانی کامل از راست‌چین (RTL) برای فارسی

## پیش‌نیازها

قبل از شروع، مطمئن شوید که موارد زیر را نصب کرده‌اید:

- [Node.js](https://nodejs.org/) (نسخه 18 یا بالاتر)
- [Yarn](https://yarnpkg.com/) (مدیر بسته)

## نصب و راه‌اندازی

1. وابستگی‌های پروژه را نصب کنید:

```bash
yarn install
```

2. سرور توسعه را اجرا کنید:

```bash
yarn dev
```

پروژه در آدرس `http://localhost:5173` در دسترس خواهد بود.

## ساخت برای تولید

برای ساخت نسخه تولیدی پروژه:

```bash
yarn build
```

فایل‌های ساخته شده در پوشه `dist` قرار خواهند گرفت.

## پیش‌نمایش نسخه تولیدی

برای پیش‌نمایش نسخه تولیدی:

```bash
yarn preview
```

## ساختار پروژه

```
resume/
├── public/              # فایل‌های استاتیک (اختیاری - می‌توانید resources را اینجا قرار دهید)
├── resources/           # فایل‌های استاتیک (تصاویر و ...)
│   └── images/         # تصاویر پروژه
├── src/
│   ├── components/      # کامپوننت‌های React
│   │   ├── Sidebar.jsx
│   │   └── Navbar.jsx
│   ├── pages/           # صفحات اصلی
│   │   ├── About.jsx
│   │   ├── Resume.jsx
│   │   ├── Portfolio.jsx
│   │   ├── Blog.jsx
│   │   └── Contact.jsx
│   ├── App.jsx          # کامپوننت اصلی
│   ├── main.jsx         # نقطه ورود
│   └── index.css        # استایل‌های اصلی
├── index.html
├── package.json
├── tailwind.config.js   # تنظیمات Tailwind
├── vite.config.js       # تنظیمات Vite
└── postcss.config.js    # تنظیمات PostCSS
```

**نکته مهم:** در Vite، فایل‌های استاتیک باید در پوشه `public` قرار گیرند. اگر پوشه `resources` در ریشه پروژه است، برای تولید نسخه نهایی باید آن را به `public` منتقل کنید یا از یک ابزار کپی استفاده کنید.

## تکنولوژی‌های استفاده شده

- **React** - کتابخانه UI
- **React Router** - مدیریت مسیریابی
- **Tailwind CSS** - فریمورک CSS
- **Vite** - ابزار ساخت و توسعه
- **Ionicons** - آیکون‌ها

## صفحات

- **درباره من** - اطلاعات شخصی و خدمات
- **رزومه** - تحصیلات، سوابق کاری و مهارت‌ها
- **نمونه کارها** - پروژه‌های انجام شده با فیلتر دسته‌بندی
- **بلاگ** - مقالات و پست‌های بلاگ
- **تماس با من** - فرم تماس و نقشه

## سفارشی‌سازی

برای تغییر رنگ‌ها و استایل‌ها، فایل `tailwind.config.js` را ویرایش کنید.

برای تغییر محتوا، فایل‌های مربوطه در پوشه `src/pages/` را ویرایش کنید.
